Explain an unfamiliar idea

Help a listener understand a new term.

Level ranges are study guidance. Start with the examples and choose your own pace.

CATEGORY

A library is a place where people can borrow books.

Start with a familiar kind of thing.

EXAMPLE

You can borrow a novel and return it later.

Make the activity concrete.

CHECK

How is borrowing different from buying?

Ask about the important distinction.

Understand

The useful distinction

Start with a familiar category, then describe the defining feature and give a concrete example. A commuter is a person who regularly travels between home and work. The example should clarify the definition, not replace it.

Adjust the detail to the listener. Ask what they already know and check understanding with a useful question. Avoid explaining one unfamiliar word through several more unfamiliar words. An analogy helps only if you also state where it differs.
