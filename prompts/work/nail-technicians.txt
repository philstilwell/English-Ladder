5. Finish with two new four-choice collocation questions for later review, with a clearly separate answer key. Do not claim to schedule a reminder.

Lesson 01: Clarifying the service and the intended length
Original fictional case: Client Zoe booked an overlay but calls the appointment a full set when speaking to technician Lin. Zoe points to a long reference image, then explains that the current short length should be kept. No work has begun. Lin clarifies that the intended discussion is a natural-nail overlay without adding length, not automatically extensions. The image is a reference for the look, not permission to copy its length. Product choice, any further design details, and suitability still need the normal consultation.
Language workshop: The picture is long; the request is short
Communication goal: Clarify the desired length before treating an ambiguous service label or reference photograph as an instruction.
Language guidance: Overlay is a broad coating term, and full set can be used loosely. In this conversation, the client wants a natural-nail overlay at the current short length, with no extensions requested. Confirm the result before relying on either label.
Useful expressions (preserve the supplied facts): When you say full set, do you mean added length? / Would you like to keep your current length? / Your booking currently says overlay. / The photo shows long nails, but we should confirm your own length preference. / You want your current short length retained. / We are discussing a natural-nail overlay without added length. / No extensions are requested at this stage. / We have not selected the product system yet. / Which part of the image do you want to use as a reference? / No work has begun, so let us settle the details first. / Service names can be used differently; the result you want is what matters. / Adding length would be a different part of the service discussion. / Please correct me if short does not describe what you mean. / Suitability still needs the normal consultation. / Current short length, natural-nail overlay discussion, no extensions. / The picture does not override your confirmed length preference.
Vocabulary: natural nail: Client's own nail rather than an added enhancement. / nail plate: Hard visible part of the natural nail. / nail bed: Tissue beneath the nail plate. / free edge: Part of the nail extending beyond its attachment at the fingertip. / overlay: Coating over a nail surface; the exact service needs clarification. / natural-nail overlay: Coating applied over the existing natural nail without necessarily adding length. / extension: Added length beyond the existing natural nail. / enhancement: Added material used to change nail appearance or structure. / full set: Common service label whose intended scope must be confirmed. / tip: Preformed component used in some nail-extension services. / form: Temporary support used in some sculpted-enhancement services. / builder gel: Gel product category used to create enhancement structure. / acrylic: Common salon term for liquid-and-powder enhancement systems. / gel polish: Light-cured color-coating category, distinct from all enhancement services. / lacquer: Conventional nail-polish category, distinct from gel polish. / service label: Name used on a booking or menu. / reference image: Picture used to discuss selected visual features. / retained length: Existing length the client wants to keep. / added length: Extra length created by an extension service. / current length: Length present before the proposed service begins. / length preference: Client's stated choice about how long the result should be. / consultation: Discussion of the request, suitability, and proposed service. / service scope: Specific work included in the agreed appointment. / read-back: Repetition of key details to verify understanding.
Speaking task: Read the booking clarification, stressing keep my own length and without adding length. Switch roles and read the plate-versus-bed and builder-gel-versus-gel-polish exchanges with the definitions intact. Complete and check the transfer; retain medium length rather than the short length used in the main dialogue.
Partner: Zoe: Client / Lin: Nail technician
Guided response task: Select supplied answers for the dialogue gaps. Check the explanations, then read the completed exchange aloud; no original writing is required.
Optional second-round challenge: A client shows a long reference but wants the existing medium length retained. The discussion is a natural-nail overlay with no extensions requested. Product choice is still open, and no work has begun.
Model for comparison AFTER my attempt, not a response to give me first: Zoe: Could you repeat the main point before we start? I want to be sure I explained it properly.
Lin: Here's the read-back: natural-nail overlay discussion, current short length kept, no extensions. Product and suitability still need consultation.
Zoe: Yes, that's right. I want the look discussed, not the long length copied.
Lin: Understood. That's the length preference we'll work from. Nothing has begun, so we can clarify the remaining choices first.
END REFERENCE
