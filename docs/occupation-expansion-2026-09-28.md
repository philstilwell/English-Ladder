# Occupation Expansion: 28 September 2026

## Scope

Added the 25 approved occupations to the existing 41 English for Work courses.
The complete directory now contains 66 courses, 528 lessons, and 264 PDFs.
The new material is authored by occupation, not generated by substituting job
names into shared dialogue templates.

The new collection contains:

- 200 distinct fictional workplace cases and model responses.
- 600 titled ten-turn lesson conversations and 200 extended twelve-turn dialogues.
- 400 four-choice dialogue questions, with feedback for every option.
- 800 collocations and 814 defined terminology entries.
- Two supported speaking scenarios per lesson, with known facts, roles,
  complications, and success checks.
- 100 new PDFs: 25 teacher guides, learner workbooks, conversation labs, and
  vocabulary/phrasebooks.
- 54 primary occupational reference entries across the source files.

Each new webpage retains the existing lesson navigation, default-closed
conversation accordions, optional local progress saving, glossary search,
download links, and complete AI-practice prompts. New activities, including
their AI extensions, do not require open-ended writing. The existing 41-course
content remains separate and is not represented as newly authored material.

## Editorial Review

Six writers authored disjoint occupation groups. The parent reviewed cases,
answer choices, specialist vocabulary, representative scripts, and integration.
Every new course also received an independent second-reader review; those
findings were corrected before the final build.

Corrections included competing valid answers, speaker reversals, unsupported
assumptions, missing identifiers and input values, inconsistent status wording,
and customer or child speech that sounded like teaching notes. More concrete
automotive terminology was added and used in context. Laboratory notification
practice now supplies all fictional analytes, values, units, and recipient facts
without teaching diagnosis, treatment, or universal critical thresholds.

The sources distinguish language practice from licensed or safety-critical work.
Regional terminology is explained where useful. No case uses actual patient,
client, employee, or customer records.

## Illustrations and Print

The 25 new illustrations were generated with Google Gemini and share the
existing visual character. The original atlas is preserved in
`assets/work/occupation-icons.png`; explicit mappings keep each occupation's
image consistent on its card, page, and PDF cover. Captions are cropped out
without altering the source image. English Ladder and its ladder mark remain
in the site header and document footer.

PDF proofs exposed short explanations and AI links stranded on otherwise empty
pages. New-course layouts were adjusted to separate vocabulary from practice,
keep related phrasebook material together, and position prompt links at their
headings. Spoken-text font sizes were not reduced. All 25 cover illustrations
and all 25 desktop/mobile page headers were visually reviewed.

## Maintenance

`content/work/occupations/README.md` documents the authoring contract.
`work_occupations.py` holds the explicit inventory and source validation.
The web and PDF publishers consume these same source files.

The answer rotation now preserves each question's authored correct index,
instead of assuming its first option is correct. A regression test checks the
answer and all four explanations against the source.

After changing curriculum or shared prompt content, rebuild all work PDFs,
regenerate the webpages, then run the complete tests and document audit.
For browser review, serve the repository locally and run
`node audit_work_occupations.cjs`; it defaults to port 8878 and also accepts
`AUDIT_ORIGIN`. Its temporary screenshots are stored in
`tmp/occupation-review/`.

No new paid text API or separately billed image API was used. The existing
signed-in Gemini subscription supplied the artwork. No external repository or
dependency was installed for this expansion.

Untracked shared-folder duplicate PDFs with numbered filenames were left
untouched and excluded from the release, as were unrelated `.DS_Store` files.
