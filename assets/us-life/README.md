`unit-icons-colorful.jpg` is the original 1696 × 2528 image created with Google
Gemini on September 30, 2026, using the signed-in Gemini Pro subscription with
no separately billed API calls. `unit-icons-colorful.webp` is the optimized
website copy, saved at quality 90 with the original dimensions and composition.

The four-column, six-row sheet follows `ICON_UNITS` in `us_life_content.py`.
`us-life-audio.css` displays the same image in the unit chooser and lesson
headings. Each cell has a 159:158 aspect ratio. Keep the artwork, reading order,
and CSS dimensions together when replacing the sheet.

The attached style reference was `assets/work/professional-icons.png`.
The brief requested detailed editorial miniatures with thin navy outlines,
dimensional shading, warm coral and gold, cobalt, teal, green, and violet.
Each unit combines recognizable everyday objects, such as luggage and a plane,
groceries and a cart, a taxi and a map, or tailoring tools and fabric. The new
artwork replaces the earlier flat blue-and-teal symbols. The old sheet remains
recoverable in Git history.
