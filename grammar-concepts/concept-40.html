QUANTITY

Understand

The useful distinction

Use so before an adjective or adverb: so helpful, so quickly. Use such before a noun phrase: such a helpful person, such helpful people. With a singular countable noun, keep a or an.

Use so with many, much, few, and little when these describe quantities: so many books, so little time. A following that clause can give a result: It was so noisy that I left. Emphasis is a choice, not a factual measurement.
