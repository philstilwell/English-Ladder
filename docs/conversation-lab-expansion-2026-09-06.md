# Conversation Lab expansion - September 6, 2026

All 41 Conversation Lab PDFs now include 368 complete fictional workplace dialogues with 2,384 speaking turns and 31,460 words of spoken dialogue. Each has 8-14 scripts with at least two speakers, plus the existing eight independent role-play cases.

The scripts cover routine coordination, planning, technical review, client communication, evidence interpretation, troubleshooting, and difficult conversations. They use professional roles and natural field terminology. The 256 new scripts are supplemented by 112 revised and restored scripts from the existing site source. These are original training scripts, not recorded conversations.

Each PDF includes a linked scenario index, speaker labels, vocabulary or language-noticing notes, rehearsal tasks, feedback guidance, bookmarks, and embedded fonts. Original download addresses are preserved, with fresh version identifiers and page counts on course pages.

## Maintenance

Author transcripts in `content/work/dialogues/`. `work_dialogues.py` validates and renders them; the default PDF generator includes them automatically. To update only the Conversation Labs, run:

```sh
python3 generate_work_documents.py --kind conversation
python3 generate_efsp_web_pages.py
python3 -m unittest discover -s tests -p "test_work*.py"
python3 audit_conversation_labs.py
```

The separate dialogue checksum means a script change requires new Conversation Labs without forcing changes to unrelated workbooks. Shared curriculum changes still require the existing full-document rebuild.
